# BetterGiggle Website — repo guide

This repo holds the **code only** for the BetterGiggle website (single-page `index.html` plus images).

## The MAIN BRAIN lives in Google Drive

All project context, notes, briefs, decisions and Chris's knowledge base live in the
Google Drive folder **`Claude_Knowledge_Library`** — that is the single source of truth
across every platform (Claude web, mobile, desktop, Claude Code, Cowork).

At the start of a session, if you have Google Drive access:

1. Read `_MAIN_BRAIN.md` in `Claude_Knowledge_Library`
   (folder: https://drive.google.com/drive/folders/1oPYM7yLIIa0ElqWVCwBfPp6zbf0hQd2W)
2. For work on this website, read the project file
   `00_projects/bettergiggle_website/PROJECT_STATUS.md`
   (folder: https://drive.google.com/drive/folders/1qGnVMmRkoq07_RW18eNJw3zNAnYQxVL9)
3. After finishing, add a one-line entry to the LOG in that `PROJECT_STATUS.md`

If you don't have Drive access in the session, say so and carry on with the code task.

## Repo facts

- Default branch: `main`; develop on feature branches
- Site: original stick figure animation ("Stick Men Series" on YouTube)
- Main file: `index.html`; images in `img/` and repo root (avatar, banner, logos)
- Anything Chris needs to read on his phone goes in the Drive project folder, not in this repo
